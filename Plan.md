# 12-Week C++ + DSA Roadmap for Beginners

This roadmap is designed to build programming fundamentals first, then gradually move into problem-solving and advanced DSA concepts. The sequence matters because DSA becomes much easier when the learner already understands memory, functions, recursion, and object-oriented thinking.

The structure follows this progression:

1. Learn how code works
2. Learn how memory works
3. Learn how data is organized
4. Learn how algorithms manipulate data
5. Learn optimization and problem-solving patterns

---

# Week 1 — Introduction to Programming with C++

## Goals

Build comfort with syntax, logic building, and writing simple programs.

## Topics

* Structure of a C++ program
* Variables and data types
* Input/output (`cin`, `cout`)
* Operators
* Conditional statements (`if`, `switch`)
* Loops (`for`, `while`, `do-while`)
* Basic debugging

## Practice Problems

* Even/Odd checker
* Largest of 3 numbers
* Multiplication table
* Reverse a number
* Palindrome number
* Armstrong number
* Pattern printing

## Why This Comes First

Students must first become comfortable writing and running programs before learning deeper concepts. Logic-building through loops and conditions is the base of all DSA.

---

# Week 2 — Functions, Arrays, and Strings

## Topics

* Functions
* Function parameters and return types
* Scope of variables
* Arrays (1D and 2D)
* Strings and character arrays
* Basic time complexity idea

## Practice Problems

* Find maximum/minimum in array
* Linear search
* Frequency count
* Reverse array
* Matrix addition
* String palindrome
* Count vowels/consonants

## Why This Sequence Works

Arrays are the simplest data structure and help students understand indexing and memory organization. Functions also teach modular programming.

---

# Week 3 — Pointers and Memory Management

## Topics

* What pointers are
* Address operators
* Pointer arithmetic
* Pointers with arrays
* Dynamic memory allocation (`new`, `delete`)
* Dangling pointers
* Memory leaks

## Practice Problems

* Swap using pointers
* Dynamic array creation
* Traverse arrays using pointers
* Pointer-based string operations

## Why This Is Important

Pointers are one of the biggest strengths of C++. Understanding memory deeply makes linked lists, trees, and graphs much easier later.

---

# Week 4 — Object-Oriented Programming (OOP)

## Topics

* Classes and objects
* Constructors/destructors
* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Access modifiers

## Practice Problems

* Student management system
* Bank account class
* Employee payroll mini-project
* Shape hierarchy using inheritance

## Why OOP Before DSA

OOP develops structured thinking and teaches how large systems are designed. It also prepares learners for interview coding and real-world software development.

---

# Week 5 — Recursion and Complexity Analysis

## Topics

* Recursion basics
* Recursive stack flow
* Base condition
* Time complexity
* Space complexity
* Big-O notation

## Practice Problems

* Factorial
* Fibonacci
* Sum of digits
* Power function
* Recursive binary search
* Tower of Hanoi

## Why This Timing Is Effective

Recursion is required for trees, divide-and-conquer algorithms, and backtracking. Complexity analysis teaches students to think beyond “working code.”

---

# Week 6 — Searching and Sorting Algorithms

## Topics

### Searching

* Linear Search
* Binary Search

### Sorting

* Bubble Sort
* Selection Sort
* Insertion Sort
* Merge Sort
* Quick Sort

## Key Concepts

* Divide and conquer
* Stable vs unstable sorting
* Best/worst time complexity

## Practice Problems

* Search in sorted array
* First/last occurrence
* Sorting custom arrays
* Merge two sorted arrays

## Why This Module Matters

Searching and sorting are foundational algorithmic patterns used everywhere in software engineering interviews.

---

# Week 7 — Linked Lists

## Topics

* Singly linked list
* Doubly linked list
* Circular linked list
* Insertion/deletion
* Reverse linked list
* Floyd cycle detection

## Practice Problems

* Reverse linked list
* Detect loop
* Middle of linked list
* Merge two sorted lists
* Remove duplicates

## Why After Pointers

Linked lists become intuitive only after students understand memory addresses and dynamic allocation.

---

# Week 8 — Stacks and Queues

## Topics

### Stack

* Stack implementation
* Applications of stack
* Infix, postfix conversion

### Queue

* Queue implementation
* Circular queue
* Deque
* Priority queue basics

## Practice Problems

* Valid parentheses
* Next greater element
* Implement stack using queue
* Implement queue using stack

## Why This Sequence Works

Stacks and queues teach controlled data access patterns and are heavily used in recursion, parsers, scheduling, and BFS/DFS.

---

# Week 9 — Trees and Binary Trees

## Topics

* Tree terminology
* Binary tree
* Binary Search Tree (BST)
* Tree traversals
* Height/depth
* Recursive tree algorithms

## Practice Problems

* Inorder/Preorder/Postorder traversal
* Level-order traversal
* Height of tree
* Validate BST
* Lowest common ancestor

## Why Trees Come Here

Trees combine recursion, pointers, and structured data traversal. By now, students have enough foundation to handle them.

---

# Week 10 — Heaps and Hashing

## Topics

### Heap

* Min heap
* Max heap
* Heap operations
* Heap sort

### Hashing

* Hash tables
* Collision handling
* `unordered_map`
* `unordered_set`

## Practice Problems

* Top K elements
* Frequency counting
* Heap implementation
* Two Sum problem

## Why This Is Important

Hashing introduces optimization thinking, while heaps are critical for priority-based problems and competitive programming.

---

# Week 11 — Graphs and Graph Algorithms

## Topics

* Graph representation
* BFS
* DFS
* Cycle detection
* Topological sort
* Shortest path basics

## Practice Problems

* Number of islands
* BFS traversal
* DFS traversal
* Detect cycle
* Shortest path in unweighted graph

## Why Graphs Are Later

Graphs are one of the hardest beginner topics because they combine recursion, queues, trees, and complex traversal logic.

---

# Week 12 — Advanced Problem Solving + Revision

## Topics

* Sliding Window
* Two Pointers
* Greedy basics
* Intro to Dynamic Programming
* Revision of all DSA topics
* Mock interviews

## Practice Problems

* Longest substring without repeating characters
* Kadane’s Algorithm
* Coin change
* Climbing stairs
* Activity selection

## Final Goals

By the end of Week 12, the learner should:

* Write clean C++ code confidently
* Understand memory and pointers
* Solve medium-level DSA problems
* Understand how to analyze algorithms
* Be ready for coding interviews and competitive programming basics

# Recommended Learning Strategy

## Daily Structure (2–3 Hours)

* 45 mins → Learn concept
* 45 mins → Watch examples/write notes
* 60 mins → Solve problems
* 15 mins → Revise mistakes

## Best Habit for Growth

Do not jump directly to solutions. Spend at least 20–30 minutes thinking independently before checking hints.

## Ideal Progression

* First focus on correctness
* Then improve time complexity
* Finally improve coding speed and code quality

---

# Expected Outcome After 12 Weeks

A student who completes this roadmap seriously should be able to:

* Solve beginner to intermediate DSA problems
* Build strong C++ fundamentals
* Crack internship-level coding rounds
* Understand interview problem-solving patterns
* Transition into advanced topics like Dynamic Programming and System Design later on
